# Portfolio

Auto-updating React portfolio website with GitHub integration.

## Features

- Auto-syncs with GitHub every 5 minutes
- Real-time project updates
- GitHub statistics and contributions
- Dark/light theme support
- Interactive animations
- Responsive design

## Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- GitHub API (Octokit)
- SWR for data fetching

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```
VITE_GITHUB_TOKEN=your_github_token
VITE_GOOGLE_FORM_ID=your_form_id
```

## Deployment

Optimized for Vercel deployment.
